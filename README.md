# Лабораторная работа №1. Быстрое погружение в язык Dart


Данный проект выполнен в рамках лабораторной работы по изучению языка программирования Dart.
В лабораторной работе рассматриваются подготовка, синтаксис, основные типы данных, 
функции и null safety, создание косольного приложения.

### Запуск проекта:
    1. Клонировать репозиторий: `git clone <url>`
    2. Перейти в папку: `cd lab1_dart`
    3. Установить зависимости: `dart pub get`
    4. Запустить: `dart run`

### Было изучено:
    1. Создание консольного приложения на языке Dart
    2. Синтаксис языка Dart
    3. Создание переменных и базовые типы данных
    4. Синтаксис функций 
    5. Условные операторы и циклы

### Ответы на вопросы:
    1. Cтатическая типизация Dart позволяет эффективнее компилировать код, 
       ускоряя работу программы
    2. `String?` позволяет содержать в переменной null, по умолчанию 
       `String` не может содержать null
    3. `final` запрещает повторное присваивание значения переменной, 
        что позволяет исключить случайные изменения
    4.  Именованный параметр `{required String name}` отличется от позиционного тем, 
        что при вызове функции нужно обязательно указать имя параметра, 
        также параметры можно указывать в любом порядке. Позиционный параметр 
        передается по порядку без указания имени

```dart
void hello({required String name, required int age}) { 
    print('$name, $age'); 
} 
        
hello(name: 'Артём', age: 20);

```
